Urutan FE yang paling efisien sekarang:

Di Product Detail, tampilkan course_id status.
Buat CTA Create Course (jika course_id null).
Buat CTA Link Existing Course (opsional awal bisa dropdown/search slug).
Setelah course_id ada, render section Course Content:
edit basic course (title, slug, description, publish)
list/add/edit/delete module
list/add/edit/delete lesson per module
Tambahkan tombol Open Public Preview ke /public/courses/:slug.
(Opsional tahap berikut) panel Grant Access by user_id.
Minimal API FE yang dipanggil:

GET /products/:id
PATCH /products/:id (set course_id)
POST /courses, PATCH /courses/:id
GET /courses/:id
POST/PATCH/DELETE /courses/:courseId/modules...
POST/PATCH/DELETE /courses/:courseId/modules/:moduleId/lessons...
